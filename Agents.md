# Algorand Agent Skills Reference

This project contains several Algorand-specific skills designed to assist in developing on the Algorand blockchain. Use these as references for smart contract development, frontend integration, and ecosystem research.

> [!IMPORTANT]
> For all Algorand-specific technical questions, refer to the local [ALGO_DOCS.md](file:///home/sayan/Programs/Hackatron/ALGO_DOCS.md) file. It contains the full official documentation.

## 🔗 Algorand Core
- **Path**: [algorand-core](file:///home/sayan/Programs/Hackatron/.agents/skills/algorand-core/SKILL.md)
- **Description**: Foundational mental model for the Algorand Virtual Machine (AVM). Covers AVM concepts, stack machine, resource limits, and Puya compiler (TS/Python to TEAL). Use when encountering AVM concepts, stack machine questions, resource limit errors, opcode budget issues, program size problems, or constraint errors.

## 🛠️ Algorand Project Setup
- **Path**: [algorand-project-setup](file:///home/sayan/Programs/Hackatron/.agents/skills/algorand-project-setup/SKILL.md)
- **Description**: Scaffolds Algorand projects using AlgoKit CLI, manages LocalNet, and retrieves code examples from official GitHub repositories. Use when initializing projects with `algokit init`, running build/test/deploy commands, starting or resetting LocalNet, or searching for Algorand contract examples.

## 🌐 Algorand Frontend
- **Path**: [algorand-frontend](file:///home/sayan/Programs/Hackatron/.agents/skills/algorand-frontend/SKILL.md)
- **Description**: Builds Algorand dApp frontends with wallet integration and typed contract clients. Supports React, Vue, SolidJS, Svelte, and vanilla JS/TS via `@txnlab/use-wallet`. Covers the signer handoff pattern, wallet provider setup, network configuration, and calling contract methods from frontend code.

## 📊 Algorand Ecosystem
- **Path**: [algorand-ecosystem](file:///home/sayan/Programs/Hackatron/.agents/skills/algorand-ecosystem/SKILL.md)
- **Description**: Catalog of major projects, protocols, and tools in the Algorand ecosystem. Use when researching DeFi protocols (Folks Finance, Tinyman, Pact), wallets (Pera, Lute, Defly), bridges, explorers, NFT marketplaces, and real-world assets (Meld Gold, Lofty).

## 💸 Algorand x402 TypeScript
- **Path**: [algorand-x402-typescript](file:///home/sayan/Programs/Hackatron/.agents/skills/algorand-x402-typescript/SKILL.md)
- **Description**: Builds x402 HTTP-native payment applications on Algorand using TypeScript. Covers clients (fetch, axios), servers (Express, Hono), facilitators, paywalls, Next.js integration, and the `@x402-avm` core library.
